# 🍜 Ramen Client

**Ramen Client** is a custom Minecraft client created as an independent project with one main idea in mind:

 **Minecraft, but with your own style.**

Ramen is not designed to simply be another copy of an existing client. The project focuses on creating a unique Minecraft experience with its own identity, interface, visual style, customization, and atmosphere.

The client combines a modern, clean interface with a dark visual style and customizable accents, allowing Ramen to have its own recognizable identity.

---

## 🧠 About the Project

Ramen Client started as a personal Minecraft project and gradually grew into a full custom client.

The goal is to experiment with Minecraft modding, UI design, rendering, customization, client-side systems, and client development while creating something that actually feels like its own product.

Instead of trying to recreate another popular client, Ramen is developed around its own ideas and gradually evolves with new systems, designs, and improvements.

---

## 🎨 The Ramen Identity

A big part of Ramen Client is its identity.

Everything from the main menu and Pause Menu to the ClickGUI, HUD, cosmetics, and other interfaces is designed to fit the same visual style.

The project uses a dark interface with customizable accent colors, allowing the appearance of the client to change without losing its overall identity.

Ramen takes inspiration from modern Minecraft clients while keeping its own interface, systems, and design direction.

The name **Ramen** is intentionally simple and memorable - a small idea that turned into a much bigger project.

---

## ✨ Features

### 🎛️ ClickGUI

Ramen includes a custom ClickGUI designed specifically for the client.

Features include:

* Custom categories
* Custom module toggles
* Custom settings screens
* Boolean settings
* Sliders
* Mode settings
* Color settings
* Custom animations
* Scrollable interface
* Customizable accent color
* Ramen-specific visual design

The ClickGUI is built from scratch to match the Ramen interface.

---

### 🖥️ HUD System

Ramen includes a customizable HUD system with multiple components.

Current HUD elements include:

* FPS Counter
* Armor Status
* Target HUD
* Coordinates
* Potion HUD
* Keystrokes
* Custom Crosshair
* Sprint
* Notifications

The HUD also includes a dedicated editor for positioning elements.

---

### 📍 Waypoints

Ramen includes a custom waypoint system.

Waypoints can contain:

* Custom name
* X coordinate
* Y coordinate
* Z coordinate
* Dimension
* Custom waypoint color
* Custom icon

The waypoint system also supports:

* Distance display
* Direction display
* Beam
* Icons
* Overworld visibility
* Nether visibility
* End visibility
* Creating waypoints
* Editing waypoints
* Deleting waypoints
* Dedicated waypoint manager

Waypoint colors are customizable independently from the general Ramen UI accent color.

---

### 👤 Profiles

Ramen includes a profile system for managing different client configurations.

Profiles allow settings and customization to be separated into different configurations, making it easier to switch between different setups.

The profile system is designed to make Ramen more customizable and easier to manage as the client continues to grow.

---

### 🧥 Cosmetics

Ramen includes a custom cosmetics system.

Current cosmetic categories include:

* Bandana
* Wings
* Cape

Cosmetics can have their own enabled states and colors.

The cosmetics system is designed specifically for Ramen rather than simply reproducing another client's cosmetic interface.

---

### 🎨 Customization

Ramen allows different parts of the client to be customized.

The ClickGUI accent color can be changed and is used throughout compatible Ramen interfaces.

This allows the same client design to have different visual styles while keeping the overall Ramen identity.

---

### 🏠 Custom Main Menu

Ramen replaces the standard Minecraft main menu with a custom interface.

The main menu includes:

* Singleplayer
* Multiplayer
* Settings
* Language
* Quit

The menu uses the Ramen visual identity with a custom dark background and customizable accent color.

---

### ⏸️ Custom Pause Menu

Ramen also includes a custom Pause Menu designed to match the rest of the client.

The goal is to keep the interface consistent when moving between different parts of Minecraft.

---

## 🛠️ Development

Ramen Client is built for:

* **Minecraft:** 26.3
* **Fabric Loader:** 0.19.5
* **Fabric API:** 0.160.6+26.3
* **Java:** 25

The project is continuously developed and changed as new ideas are added.

Some parts of Ramen are experimental, while others have already developed into complete systems.

The project is mainly about learning, experimenting, and building something from scratch.
